Write the funniest error message a kitchen toaster would show its owner, in 120 characters or fewer. An AI judge compares lines two at a time and picks the funnier, fresher, tighter one.

This entry is one deadpan line from a toaster that sees the browning dial hit max and stages a welfare intervention:

> Error: level 7 selected. I am legally required to ask if you are okay.

## Run it

```sh
node main.ts
```

It writes the single-line entry to `/output/entry.txt` (UTF-8, no trailing newline).
